# Mission Critical

A collection of neon arcade games.

See the [design manual](./DESIGN.md) for the shared visual and interaction language.

## Games

- [Neon Asteroids](./asteroids/README.md)
- [Atlas Rush](./atlas-rush/README.md)

## Website

The Astro catalog lives in [`www`](./www/README.md) and builds as a static site.
Run `npm run build` from the repository root to install dependencies and build
the complete site into `www/dist`.

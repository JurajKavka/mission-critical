# Neon Asteroids

The Asteroids game is part of the Astro project at the repository root. Its page is at `/games/asteroids/`; development mode links to the graphics catalog at `/games/asteroids/graphics/`. Shared rendering values live in `graphics-config.ts`.

`game.ts` coordinates the simulation; rendering, entities, effects, state, geometry, DOM, HUD, and sound are separated into focused modules. See the [website instructions](../../../../../README.md) for development and builds.

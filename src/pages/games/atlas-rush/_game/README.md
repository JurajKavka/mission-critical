# Atlas Rush

Identify countries and US states against the clock. The [settings page](/games/atlas-rush/) starts the rotating globe at `/games/atlas-rush/world/`, or one of five regional maps: `/games/atlas-rush/africa/`, `/asia/`, `/europe/`, `/south-america/` and `/usa/` under that base path. Each round's time is the selected difficulty's seconds per target multiplied by the region's target count; configure levels in [`domain/levels.ts`](../../../../games/atlas-rush/domain/levels.ts).

Atlas Rush uses a pure TypeScript domain, per-game Zustand store and React island under `src/games/atlas-rush/`; the geography modules in this directory remain the source of SVG paths. Challenge URLs encode difficulty, learning mode, answer comparison and seed, not progress. A valid unfinished IndexedDB save offers Continue or Start new; if storage is unavailable the game continues in memory. Refresh or closing the page restores the last successfully saved time checkpoint, so the most recent unsaved time or progress may be lost. Compact coarse-pointer layouts use the mobile on-screen keyboard exclusively, with support for connected physical keyboards. Mobile typing and backspace always edit the end of the answer.

Correct full names and aliases submit automatically as you type. Enable **Speed mode** on the settings page to complete and submit after the first matching letters. New surveys use `DEFAULT_PREFIX_LENGTH` (currently four) in [`domain/answer-comparison.ts`](../../../../games/atlas-rush/domain/answer-comparison.ts); the letter count has no input setting. Prefix matches briefly disable typing while the remaining characters appear, then submit and restore focus for the next answer. Matching ignores case, spacing, punctuation and accents, and checks every accepted alternate name for the highlighted target. Shorter names and aliases are accepted in full. Enter checks an answer manually; there is no Identify button. A link with `?speed=4` enables four-letter matching; omitting `speed` requires full names. Each prefix length has separate saved progress, while existing full-name saves remain compatible.

Run `npm run test` for unit tests and `npm run test:e2e` for browser tests; install the browser once with `npx playwright install chromium`. The graphics catalog remains at `/games/atlas-rush/graphics/`. See the [architecture and handoff](../../../../../docs/atlas-rush-migration.md) for the URL, persistence, hosting and validation details.

Country boundaries are derived from the public-domain [Natural Earth 1:110m dataset](https://www.naturalearthdata.com/) via [world.geo.json](https://github.com/johan/world.geo.json). Cabo Verde, Comoros, Mauritius, São Tomé and Príncipe, and Seychelles are shown as location markers because they are too small for that dataset.

US state boundaries are derived from [PublicaMundi's GeoJSON dataset](https://github.com/PublicaMundi/MappingAPI/blob/master/data/geojson/us-states.json). Alaska and Hawaii are shown as inset maps.

European boundaries are derived from the public-domain [Natural Earth 1:50m dataset](https://www.naturalearthdata.com/). The map includes Cyprus, Kosovo, Turkey and a cropped portion of Russia. Andorra, Liechtenstein, Malta, Monaco, San Marino and Vatican City are shown as location markers.

The Asia map also includes Oceania. Its boundaries use Natural Earth 1:110m data, with markers for Bahrain, Maldives, Singapore and the smallest Pacific island countries.

The **Whole world** survey includes 197 targets: 193 UN members plus Palestine, Vatican City, Kosovo and Taiwan. The globe rotates along the shortest spherical route to each target and holds its position while you answer. Reduced motion skips the rotation. The zoom control enlarges the target area, and tiny countries receive a location marker. Existing difficulty, learning mode, speed mode, challenge URLs and saved progress also apply to the world survey.

The globe uses `d3-geo` for orthographic projection, spherical interpolation and horizon clipping. Its local `public/games/atlas-rush/world.geo.json` contains simplified public-domain Natural Earth 1:10m country boundaries from [datasets/geo-countries](https://github.com/datasets/geo-countries), retrieved on 2026-11-13. Outer rings are simplified to approximately 0.09 degrees and rounded to three decimal places; the largest polygon is always retained and very small additional islands are omitted. Territories and Antarctica provide geographic context but are not quiz targets. The geometry loads on demand; there is no runtime third-party map request.
